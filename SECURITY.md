# Politique de sécurité

## Signalement de vulnérabilité

Si vous découvrez une vulnérabilité de sécurité dans Moment, merci de nous en informer de manière responsable.

### Comment signaler

Envoyez un e-mail à : **security@example.com** (à remplacer par l'adresse réelle)

Indiquez dans votre message :
- Une description détaillée de la vulnérabilité
- Les étapes pour la reproduire
- L'impact potentiel

### Engagements

Nous nous engageons à :
- Répondre à votre signalement dans les 48 heures
- Tenir informé de l'avancement de la correction
- Créditer votre contribution (si vous le souhaitez)
- Ne pas engager de poursuites légales pour les recherches de sécurité menées de bonne foi

### Ce que nous n'acceptons pas

- Attaques sur des systèmes de production
- Accès non autorisé aux données
- Divulgation publique avant correction
- Utilisation de la vulnérabilité à des fins malveillantes

## Versions supportées

Seules les versions actuelles de Moment sont supportées pour les rapports de sécurité.

## Remerciements

Nous remercions tous les chercheurs en sécurité qui contribuent à améliorer Moment.
